## About

I'm an independent developer interested in understanding how systems work and turning ideas into practical software.

My work and experiments currently span:

- **AI Engineering** — agent workflows, model integrations, and developer tools.
- **Software Development** — web applications, Android projects, and useful utilities.
- **Cybersecurity** — security tooling, privacy, and learning-oriented projects.
- **Systems & Networking** — Linux, automation, local infrastructure, and hardware experiments.

I prefer building, testing, documenting, and improving real things over collecting technology buzzwords.
